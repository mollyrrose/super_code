# Summary

AstrBot is an open-source agent/chatbot framework that wires LLMs and a
large plugin ecosystem (1,000+ one-click-installable plugins claimed) into
common IM platforms. AGPL-3.0, Python. ~45.9k stars, 3.4k forks, 5,495
commits, 744 open issues, 421 open PRs.

# Repo / source check

Strong, long-running-project signals: documentation site, changelog
directory, test suite, pre-commit config, multi-language README, Docker Hub
distribution, DeepWiki and Trendshift listings, and active community
channels. Commit depth (5,495) and fork count (3.4k) are consistent with
genuine multi-year adoption rather than a trending-page star spike; the
744-issue backlog is large but proportionate to project size/activity, not
itself a red flag.

# Why this is in the radar

A mature, IM-platform-centric agent framework — distinct niche from the
coding-agent-harness tools already tracked here (ruflo-swarm-harness,
openclaw). Worth awareness as the reference point for "agent framework
wired into chat platforms" rather than "agent framework wired into a
terminal/IDE," which is the gap most of this bundle's other agent-tooling
entries cover.

# Notes

- AGPL-3.0 licensing has stricter reuse/distribution implications than the
  MIT/Apache entries elsewhere in this topic — relevant if ever considered
